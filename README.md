# School Puzzle / Assessment Application

A comprehensive School Puzzle and Assessment platform featuring Super Admin, School Admin, and Student portals, a rule-based adaptive random question engine, one-time attempt enforcement, per-question timers, and historical reporting.

## Technology Stack
- **Frontend**: Flutter (Web & Android) + Flame Puzzle Engine
- **Backend**: Node.js + Express.js REST API
- **Database**: MongoDB Atlas (with Mongoose ODM)
- **Authentication**: JWT-based auth with mandatory first-login password change
- **Adaptive Engine**: Pure rule-based progression logic (no AI required)

## System Roles & Permissions
1. **Super Admin**:
   - Initial credentials: `san` / `san` (mandatory first-login password change).
   - Multi-tenant school workspace creation.
   - School Admin creation (auto-generates unique ID for username & password).
   - Creation of additional Super Admins.
   - Question Groups and Question Bank management (Easy, Medium, Hard).
   - Test publishing (Selected Questions with shuffle & preview, or Random Questions with rule-based engine).
   - Comprehensive audit reports and publish history.

2. **School Admin**:
   - Unique Admin ID generated by Super Admin.
   - First-login forced password change.
   - Isolated dashboard displaying assigned School Name.

3. **Student**:
   - Unique Student ID credentials (first-login forced password change).
   - Access restricted to their assigned tests, one-time attempts, and individual test timeline/reports.
