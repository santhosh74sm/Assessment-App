# Puzzles Assessment Application — Requirements & Specifications

## 1. System Overview
The School Puzzle / Assessment Application is an end-to-end evaluation platform tailored for schools. It enables Super Admins to manage multiple isolated school workspaces, curate diverse question banks, publish assessment tests using rule-based algorithms or manual selection, and monitor detailed performance reports.

## 2. User Roles & Access Control (RBAC)
1. **Super Admin**:
   - Initial Super Admin account: `san` / `san` (mandatory first-login password change enabled).
   - Global multi-tenant access across all schools.
   - School and Admin creation (generates unique Admin ID where username = initial password = Admin ID).
   - Creation of other Super Admins.
   - Question Group and Question Bank authoring.
   - Test publishing (Selected Questions vs. Random Questions).
   - System-wide reports and publish history.

2. **School Admin**:
   - Unique Admin ID generated by Super Admin.
   - First-login forced password change.
   - Current view scope: Isolated view of their assigned School Name.

3. **Student**:
   - Attributes: Student Name, Class, Section, School Admission Number, Unique App Number / Student ID.
   - Username = Unique Student ID, Password = Unique Student ID (forced change on first login).
   - Isolated access: Can only view assigned tests, attempt them once, and review own results/timeline.

## 3. Assessment Lifecycle & Business Rules
- **Publish Modes**: Strictly two modes:
  1. `Selected Questions`: Multi-group, multi-difficulty manual selection; optional shuffle; Preview with Test enabled.
  2. `Random Questions`: Target-based, specifies count; rule-based adaptive selection; NO preview test.
- **Availability Window**: Defined by `StartDate`, `StartTime`, `EndDate`, `EndTime`.
- **One-Time Attempt Guarantee**:
  - Test transitions: `NOT STARTED` -> `IN PROGRESS` -> `COMPLETED` or `LOCKED / INCOMPLETE`.
  - Start instantly consumes the attempt.
  - Exiting or closing locks test permanently as `LOCKED / INCOMPLETE`.
  - Completed test is permanently locked as `COMPLETED`.
- **Per-Question Timer**:
  - Super Admin configures question duration (e.g. 30s, 45s, 60s).
  - Auto-advances when time expires; logs exact time taken.
- **Scoring Engine**:
  - 100-point normalized base score.
  - Question-level points and correct/wrong status recorded.

## 4. Rule-Based Random Question Engine
- Zero AI requirement.
- Adaptive selection based on student history:
  - Fresh student -> Easy questions.
  - High performance on Easy -> Easy + Medium.
  - High performance on Medium -> Medium + Hard.
  - Hard is the final difficulty.
- Anti-repetition window: Excludes recently attempted questions within an eligibility period.
